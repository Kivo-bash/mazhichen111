# Neural Genesis · 4K 神经网络动画

纯 Three.js + WebGL2 + GLSL ES 3.00 实现的 45 秒 3840×2160 循环动画：一个 6 层全连接网络先识别手写数字 “3”，通过反向传播反复训练，再在从未见过的 “7” 和 “0” 上验证泛化能力。直接用浏览器打开 `index.html` 即可（需联网加载 jsDelivr 上的 three@0.160）。

| 时间 | 场景 | 细节 |
| --- | --- | --- |
| 0–4s | 诞生 | 混沌粒子螺旋汇聚成 144 → 32 → 40 → 40 → 28 → 10 的网络 |
| 3.5–7.5s | 突触生长 | 3,000 条突触逐层生长（正/负权重为青/紫），每层浮现 3D 标签 |
| 5–8s | 数据输入 | 粒子流汇入 12×12 像素输入层，点亮手写数字 “3” |
| 8–12.8s | 前向传播 | 激活波逐层传递；信息面板演示单个神经元 z = Σwᵢxᵢ + b 与 ReLU |
| 12–13s | Softmax 输出 | 0–9 概率条生长，首次预测 “3” 仅 41% |
| 13.2–16.2s | 反向传播 | 梯度波反向回传，强权重变亮、弱权重淡出 |
| 16.2–26s | 反复训练 | 6 轮快速前向/反向循环，镜头环绕整个网络；Loss 曲线下降、“3” 升至 98.1% |
| 26.4–32s | 泛化测试 “7” | 新数字飞入输入层，前向传播后预测 7 · 96.4% |
| 32.2–37.3s | 泛化测试 “0” | 预测 0 · 94.7%；测试集面板 3/3 全部正确 |
| 37.4–45s | 智能涌现 | 高速推理脉冲，镜头拉远淡出 |

所有动画在 GPU 着色器中计算：神经元、突触、数据粒子、概率条、星云背景各有自定义 GLSL3 着色器；后期为 UnrealBloom + ACES 色调映射 + 色差/暗角/胶片颗粒调色，字幕与信息面板在调色 pass 中合成。

**操作**：点击重播 · `R` 录制 WebM 并下载 · `F` 全屏

**URL 参数**：`?w=1920&h=1080` 低配预览，`?t=9.5` 冻结在某一帧。

> 录制使用 MediaRecorder 实时捕获，若 GPU 跑不满 4K@60fps 会掉帧，可先用 `?w=&h=` 降低分辨率。
