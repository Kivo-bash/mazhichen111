# Neural Genesis · 4K 神经网络动画

纯 Three.js + WebGL2 + GLSL ES 3.00 实现的 18 秒 3840×2160 循环动画。直接用浏览器打开 `index.html` 即可（需联网加载 jsDelivr 上的 three@0.160）。

| 时间 | 场景 |
| --- | --- |
| 0–4s | 混沌粒子螺旋汇聚成 6 层神经元 |
| 3.5–7.5s | 突触逐层生长（权重正/负以青/紫区分） |
| 5–8s | 输入数据流涌入输入层 |
| 7.2–12.4s | 前向传播：激活波逐层点亮，输出层“预测”神经元爆亮 |
| 12.8–15.4s | 反向传播：梯度波反向回传，权重被“锐化”为金/青色 |
| 15.3–18s | 训练完成，高速推理脉冲，镜头拉远淡出 |

所有动画都在 GPU 着色器中计算：神经元/突触/粒子/星云背景各有自定义 GLSL3 着色器，后期为 UnrealBloom + ACES 色调映射 + 色差/暗角/胶片颗粒调色。

**操作**：点击重播 · `R` 录制 WebM 并下载 · `F` 全屏

**URL 参数**：`?w=1920&h=1080` 低配预览，`?t=9.5` 冻结在某一帧。

> 录制使用 MediaRecorder 实时捕获，若 GPU 跑不满 4K@60fps 会掉帧，可先用 `?w=&h=` 降低分辨率。
