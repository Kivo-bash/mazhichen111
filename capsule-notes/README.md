# 胶囊笔记

一个可以浏览、编辑 Markdown 文本的小工具。文本里可以插入彩色的**胶囊**，每个胶囊显示一个数字：

| 胶囊类型 | 编辑时设置 | 浏览时 |
| --- | --- | --- |
| 区间 · 随机生成 | 最小值、最大值、小数位 | 显示区间内的随机数，点一下重新随机 |
| 区间 · 用户填写 | 最小值、最大值、小数位、默认值 | 点开输入框或拖动滑块填数，超出区间会自动调整到边界 |
| 计算函数 | 公式，例如 `round(人数 * 每人预算 * 折扣)` | 显示计算结果，点开可以看到算式和代入后的数值 |

所有胶囊都可以设置名称、单位和颜色。公式通过名称引用其它胶囊，任何一个值变化，依赖它的胶囊都会立即重新计算。

## 使用

直接用浏览器打开 `index.html` 即可，不需要安装或构建。

版式参照 iOS 26 的液态玻璃设计：超大标题、文档胶囊条（当前文档为红色实心）、白色大圆角卡片，底部悬浮一条迷你条（状态、撤销重做；编辑时是格式工具）、一条「浏览 / 公式 / 编辑」玻璃标签栏和一个圆形玻璃按钮（浏览时全部重新随机，编辑时插入胶囊）。玻璃在 Chromium 内核浏览器里带 SVG 折射，其它浏览器是普通磨砂。气泡、对话框、弹窗、提示、步进器和滑块来自 [Framework7](https://framework7.io) 9.1.3，只打包了用到的组件（`vendor/`，普通脚本，双击打开也能加载；更新时运行 `npm install && npm run build:vendor`）；图标用 [Framework7 Icons](https://framework7.io/icons/)，以 data URI 内嵌在 `styles.css`。

- **浏览 / 公式 / 编辑**：底部标签栏切换；「公式」会把算式直接写在公式胶囊里。快捷键 `Ctrl/⌘ + E` 切换编辑。
- **撤销 / 重做**：迷你条右侧的按钮或 `Ctrl/⌘ + Z`、`Ctrl/⌘ + Shift + Z`，文字、胶囊设置和浏览时填的数都能撤销。
- **文档**：大标题下的胶囊条切换文档，最后一个是「新建」；长按或右键文档可以重命名、删除；点大标题也能重命名。
- **插入胶囊**：编辑时把光标放到想要的位置，点右下角的 ＋。
- **修改胶囊**：编辑模式下点击胶囊，旁边弹出设置气泡，改动即时生效；按「完成」或点空白处保留，按 Esc 或「取消」撤回这次修改。改名后，其它公式里的引用会自动更新。
- **Markdown**：支持标题、粗体、斜体、删除线、行内代码、代码块、引用、有序/无序/任务列表、表格、链接和分割线。工具栏按钮和 `Ctrl/⌘ + B / I` 可以快速插入格式，回车会自动延续列表。
- 文档保存在浏览器的 localStorage 中，可以新建多篇文档。

## 公式语法

- 运算符：`+ - * / % ^`，括号，比较 `> < >= <= == !=`（结果为 1 或 0）；也可以写 `×`、`÷`。
- 函数：`round(x, 位数)`、`min`、`max`、`sum`、`avg`、`abs`、`sqrt`、`pow`、`floor`、`ceil`、`log`、`ln`、`exp`、`sin`、`cos`、`tan`、`clamp(x, 下限, 上限)`、`if(条件, 是, 否)`。
- 常量：`pi`、`e`。
- 名称可以用中文；出现循环引用、除以 0 或引用不存在的胶囊时，胶囊会显示为红色虚线框，并给出原因。

公式由自己实现的解析器求值，不使用 `eval`。

## 目录结构

```
capsule-notes/
├── index.html        页面结构
├── styles.css        浅色主题定制（在 Framework7 之上）
├── vendor/           打包好的 Framework7 组件、样式与图标字体
├── tools/            生成 vendor 的入口文件
├── js/
│   ├── markdown.js   Markdown 渲染器（先转义再渲染，拦截危险链接）
│   ├── expr.js       公式解析与求值
│   └── app.js        文档管理、编辑器、浏览视图、胶囊对话框
└── tests/            node --test 单元测试
```
