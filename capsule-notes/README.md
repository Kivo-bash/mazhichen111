# 胶囊笔记

像备忘录一样直接在排好版的文档上写字（保存为 Markdown），文中可以插入彩色的**胶囊**，每个胶囊是一个会变化的数字：

| 胶囊 | 设置 | 用法 |
| --- | --- | --- |
| 填写 | 最小值、最大值、小数位、默认值 | 点数字直接输入，或按住胶囊左右拖动；方向键 ↑↓ 微调，Shift 十倍 |
| 随机 | 最小值、最大值、小数位 | 点一下重新抽取；「⋯」菜单里可以全部重抽 |
| 公式 | 例如 `round(人数 * 每人预算 * 折扣)` | 悬停或点一下看算式和代入后的数值 |

所有胶囊都可以设置名称、单位和颜色。公式通过名称引用其它胶囊，任何一个值变化，依赖它的胶囊都会立即重新计算。

## 使用

直接用浏览器打开 `index.html` 即可，不需要安装或构建。

- **写字**：没有「编辑 / 浏览」之分，点哪写哪。行首输入 `## ` 变标题、`- ` 变列表、`1. ` 变编号、`[] ` 变清单、`> ` 变引用、`--- ` 变分割线；`⌘B` / `⌘I` 粗体斜体。底部工具条的「Aa」里有全部格式。
- **插入胶囊**：把光标放到想要的位置，点底部的「＋ 胶囊」。
- **设置胶囊**：鼠标移到胶囊上点右上角的小按钮，或右键 / 长按胶囊。改动即时生效，按「取消」或 Esc 撤回。改名后，其它公式里的引用会自动更新。
- **撤销 / 重做**：右上角按钮或 `⌘Z` / `⇧⌘Z`，文字、胶囊设置和数值都能撤销。
- **更多**：右上角「⋯」里有全部重新随机、在胶囊里显示算式、新建文档、使用说明、删除文档。
- **文档**：左侧边栏切换、搜索、新建；向左滑动删除，右键可以重命名或删除；大标题可以直接改。宽屏常驻，窄屏点左上角按钮滑出。文档保存在浏览器的 localStorage 中。

## 界面

参照 iOS 26 的液态玻璃：玻璃几乎完全透明，脚本按每块玻璃的尺寸生成一张透镜位移图（中心为零、越靠边缘越大），通过 SVG `feDisplacementMap` 作为 `backdrop-filter`，让背后的内容只在边缘被折弯；再叠加亮边和一点内发光。Chromium 内核浏览器里有折射，其它浏览器退回轻度磨砂。

气泡、对话框、弹窗、提示、步进器、滑块和侧边面板来自 [Framework7](https://framework7.io) 9.1.3，只打包了用到的组件（`vendor/`，普通脚本，双击打开也能加载；更新时运行 `npm install && npm run build:vendor`）；图标用 [Framework7 Icons](https://framework7.io/icons/)，以 data URI 内嵌在 `styles.css`。

## 公式语法

- 运算符：`+ - * / % ^`，括号，比较 `> < >= <= == !=`（结果为 1 或 0）；也可以写 `×`、`÷`。
- 函数：`round(x, 位数)`、`min`、`max`、`sum`、`avg`、`abs`、`sqrt`、`pow`、`floor`、`ceil`、`log`、`ln`、`exp`、`sin`、`cos`、`tan`、`clamp(x, 下限, 上限)`、`if(条件, 是, 否)`。
- 常量：`pi`、`e`。
- 名称可以用中文；出现循环引用、除以 0 或引用不存在的胶囊时，胶囊会显示为红色虚线框，并给出原因。

公式由自己实现的解析器求值，不使用 `eval`。

## 目录结构

```
capsule-notes/
├── index.html        页面结构
├── styles.css        液态玻璃浅色样式（在 Framework7 之上）
├── vendor/           打包好的 Framework7 组件、样式与图标字体
├── tools/            生成 vendor 的入口文件
├── js/
│   ├── markdown.js   Markdown 渲染器（先转义再渲染，拦截危险链接）
│   ├── expr.js       公式解析与求值
│   └── app.js        文档管理、所见即所得编辑与 Markdown 互转、胶囊交互、液态玻璃透镜
└── tests/            node --test 单元测试
```
